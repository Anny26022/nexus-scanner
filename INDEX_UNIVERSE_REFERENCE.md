# Requested NSE Index Universe

This list drives the standalone official constituent refresher in the daily
and weekly pipelines. Its mapping is not consumed by the frontend, scanner,
index registry, R2 publication, or existing provider mappings.

## Standalone refresh scope

For each index below, retain a dated current-constituent mapping. The requested
member count is an observation from the supplied screen, not a validation rule:
official counts may vary at a review, corporate action, or transition.

The refresher uses official NSE Indices page-specific Index Constituent
downloads for membership. It preserves the compressed mapping and manifest
when the mapping is unchanged. Source failures are nonfatal to the core
pipeline. This reference does not enable scanner filters or UI exposure.

## Mapping record shape for later work

When this reference is acted on later, each index should produce a dated record
with `index_id`, `display_name`, `as_of_date`, `source_url`,
`observed_constituent_count`, and a list of constituent objects containing at
least `symbol`, `isin`, `company_name`, and `weight` when the source publishes
it. Missing official weights must stay null.
